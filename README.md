# iFakeGPS-iOS

Independent iPhone application integrating iFakeGPS route features with a pinned, noncommercial Roam Control Build 61 base.

Initial implementation is developed on a separate feature branch. The existing desktop iFakeGPS repository is unchanged.

Upstream: seanhowarthdev/Roam-Control, tag v0.9.2-preview-build.61, commit 19b596e737639a7a7089b7d476eee848a3255559.
